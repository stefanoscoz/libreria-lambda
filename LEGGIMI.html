Libreria LAMBDA: componente aggiuntivo personale per Excel

Un pannello dentro Excel con le formule LAMBDA dello studio. Con un clic una formula viene inserita in Gestione nomi del file aperto e si usa come una funzione, per esempio =IRPEF2026(B2). Non serve pubblicarlo sullo store: si installa solo sul proprio computer.

Cosa fa

  • Inserisci nel file: crea la funzione nel file aperto. Se esiste già, chiede conferma prima di sostituirla.
  • Inserisci tutte: inserisce in un colpo tutte le formule della libreria.
  • Nuova formula / Modifica / Elimina: gestisce la libreria. La formula si scrive nella sintassi italiana (SE, ARROTONDA, separatore punto e virgola). La descrizione diventa il commento in Gestione nomi.
  • Leggi dal file aperto: copia nella libreria le LAMBDA già presenti nel file. Excel le restituisce in inglese (IF, ROUND, virgola): il pannello le segna come "sintassi inglese" e le reinserisce correttamente.
  • Backup: mostra la libreria come testo da copiare in un file; incollando un backup si ripristina.

Formule già incluse: IRPEF2025, IRPEF2026 (imposta lorda, escluse detrazioni e addizionali), CON_IVA e SCORPORO_IVA al 22%.

Installazione (una sola volta)

Un componente aggiuntivo di Office è una piccola pagina web: Excel la carica da un indirizzo https. Per questo i file vanno pubblicati online. Il modo gratuito più semplice è GitHub Pages.

1. Pubblicare i file

  1. Crea un account gratuito su github.com (se non lo hai già).
  2. Crea un nuovo repository pubblico chiamato libreria-lambda.
  3. Carica tutti i file di questa cartella (comprese la cartella assets) con Add file › Upload files.
  4. Vai su Settings › Pages, scegli Deploy from a branch, ramo main, cartella / (root), e salva.
  5. Dopo un minuto l'indirizzo sarà https://TUO-NOME-UTENTE.github.io/libreria-lambda. Aprilo nel browser e aggiungi /taskpane.html: deve comparire il pannello.

Online ci sono solo il pannello e le formule di partenza. Le formule che aggiungi tu restano sul tuo computer. Non mettere mai dati dei clienti nelle descrizioni.

2. Inserire l'indirizzo nel manifest

Nel Terminale, dalla cartella di questi file, sostituisci TUO-NOME-UTENTE con il tuo nome utente GitHub:

sed -i '' 's#https://INDIRIZZO-DA-SOSTITUIRE#https://TUO-NOME-UTENTE.github.io/libreria-lambda#g' manifest.xml

In alternativa apri manifest.xml con TextEdit e usa Trova e sostituisci su tutto il testo https://INDIRIZZO-DA-SOSTITUIRE.

3. Installare in Excel per Mac

  1. Chiudi Excel.
  2. Nel Finder premi Cmd+Maiusc+G e incolla:
    ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef
    Se la cartella wef non esiste, creala.
  3. Copia lì il file manifest.xml (già modificato al passo 2).
  4. Riapri Excel e un file qualsiasi: nella scheda Home compare il pulsante Formule LAMBDA. Se non c'è, cercalo tra i componenti aggiuntivi della scheda Home.

Uso quotidiano

  1. Apri il file di lavoro e premi Formule LAMBDA.
  2. Premi Inserisci nel file sulla formula che ti serve.
  3. Nel foglio scrivi =IRPEF2026(B2).

La formula resta salvata nel file, quindi funziona anche per chi riceve il file senza avere il componente aggiuntivo.

Aggiornare o rimuovere

  • Per aggiornare il pannello ricarica i file su GitHub; se Excel mostra ancora la versione vecchia, chiudi e riapri Excel.
  • Per rimuoverlo togli manifest.xml dalla cartella wef e riavvia Excel.
  • Prima di svuotare la cache di Office o cambiare computer, fai un Backup: la libreria personale è salvata solo su questo computer.

Requisiti

Excel per Microsoft 365 o Excel 2024 (le funzioni LAMBDA non esistono nelle versioni precedenti). Le formule IRPEF vanno aggiornate quando cambiano soglie o aliquote: verificale sempre con i casi di prova prima di usarle sui clienti.
